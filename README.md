-Horizontal software:
____________________

-Microsoft Excel:

Microsoft Excel is horizontal software because it can be used across many industries like
healthcare, finance, manufacturing, and retail.For example in retail they can use excel
for invoices, budget and stock list.

-Difference in Scope:
_____________________

Vertical software is designed to meet the needs of a specific industry or sector.While the
horizontal software provides general-purpose functionality that can be used across multiple 
industries.

Operating System Modes:
_______________________

-Batch Processing:

Batch processing is a method where large volumes of data are collected and processed together
at scheduled times.In a business scenario, A company's monthly payroll system processes all employee
salaries at the end of the month.

-Real-Time Processing:

Real-time processing handles data immediately as it is received.In a business scenario,
An ATM banking system updates account balances instantly when a customer withdraws money.
